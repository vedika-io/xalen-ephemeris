# Getting support

XALEN Ephemeris is open source and maintained by a small team. Community help
is free; paid support is available if you need guarantees.

| You want to | Go to |
|-------------|-------|
| Ask a question, share an idea, or get help using the crates | [GitHub Discussions](https://github.com/vedika-io/xalen-ephemeris/discussions) |
| Report a bug or an accuracy discrepancy | [Open an issue](https://github.com/vedika-io/xalen-ephemeris/issues/new/choose) and pick the bug report form |
| Report a documentation problem or request a feature | The documentation and feature request forms on the same page |
| Report a security vulnerability | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue |
| Get contractual support, an SLA, or a commercial licence | [ENTERPRISE.md](ENTERPRISE.md) and hello@xalen.io |

## Before you ask

- Check the [README](README.md), [docs/ACCURACY.md](docs/ACCURACY.md) and the
  rustdoc for the crate you use.
- Search existing issues and discussions.
- For a bug, include the exact inputs (date and time with timezone or Julian
  day, latitude and longitude, ayanamsa, house system, flags) and the version
  of XALEN and of any reference tool you compared against. The bug form asks
  for these.

## What to expect

The project is maintained on a best-effort basis. There is no guaranteed
response time for community support. We read every issue and discussion, and
aim to reply to new ones within a few working days. Security reports follow the
faster timeline in [SECURITY.md](SECURITY.md). Guaranteed response times are
part of [XALEN Enterprise](ENTERPRISE.md).

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
